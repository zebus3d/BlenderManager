Configuramos un custom task para visual studio code (dentro de la carpeta de tu proyeto .vscode/task.json):
{
    // See https://go.microsoft.com/fwlink/?LinkId=733558
    // for the documentation about the tasks.json format
    "version": "2.0.0",
    "tasks": [
        {
            "label": "Run my custom python in trerminal",
            "command": "/usr/bin/python3",
            "args": [
                "${workspaceFolder}/main.py",
                "-m",
                "console"
            ],
            "console": "integratedTerminal",
            "group": {
                "kind": "build",
                "isDefault": true
            }
        }
    ]
}

De esta manera al presionar ctrl + shift + b se ejecutara el main.py con el module console 
entonces podremos presional ctrl + e y ver los widgets de nuestra aplicación.
