Notes from the original Kivy experiments (kept for reference)

I tried to give Kivy access to the input events (to silence a warning).
It does not actually fix it; it seems related to touch devices on laptops:
    sudo usermod -a -G input <user>

Custom task for Visual Studio Code (inside .vscode/tasks.json of the project):
{
    "version": "2.0.0",
    "tasks": [
        {
            "label": "Run my custom python in terminal",
            "command": "/usr/bin/python3",
            "args": ["${workspaceFolder}/main.py", "-m", "console"],
            "console": "integratedTerminal",
            "group": { "kind": "build", "isDefault": true }
        }
    ]
}
Then pressing Ctrl+Shift+B runs main.py with the console module, so you can
press Ctrl+E and inspect the widgets of the app.

Installing buildozer on Linux Mint/Ubuntu:
    sudo aptitude install autoconf automake libtool
    pip3 install --upgrade pip
    pip3 install --user Cython
    pip3 install --user buildozer
